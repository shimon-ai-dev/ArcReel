# 书籍模式验收场景

`rainy-night.txt` 是为本仓库编写的合成小说，不含第三方小说或私密信息。它是输入文本，不是已完成的模型生成示例。

## 实际模型验收准备

1. 按网站文档 `guide/book-modes` 启动 ArcReel 与独立的 IndexTTS2 桥接。将经授权的三个不同参考声音放入桥接的 reference root，分别为 `narrator.wav`、`lin-lan.wav`、`chen-zhou.wav`。这里不附带真人克隆样本，也不下载模型。
2. 创建有声书项目，完整导入 `rainy-night.txt`。不配置图像或视频端点。
3. 通过界面或 `book_project` Agent 工具建立 narrator、lin-lan、chen-zhou 三个声音。adapter 为 indextts2、model 为 IndexTTS2、base_url 为 http://127.0.0.1:7861，reference_audio 使用对应相对文件名。
4. 依照上下文把对白段分配给两位角色，叙述和“她说”等文字仍保留并朗读。自动分段默认不猜角色；如段落跨越说话人，Agent 可在保留完整源文位置和覆盖关系的前提下，用 save_document 拆分段落。未确认识别不能冒充已确认。
5. 给“原来是你呀！”所在发言设置“惊讶”的情绪描述，强度 0.8。情绪描述与八维向量二选一，不同时发送。为“她停了一会儿”之后设置 0.8 秒停顿。
6. 上传自己有使用权的脚步、雨声、开门、倒吸气音效。记录来源和授权。脚步绑定第一章相关叙述段；雨声使用 ambience 分轨、循环至章末、音量 0.25、ducking 0.25；倒吸气作为有来源的补充素材，不假称 IndexTTS2 原生发声，也不保证角色音色一致。
7. 生成全部语音，逐段试听角色一致性、惊讶表达和发音，导出 WAV，再导出 MP3。程序覆盖检查与人工听感检查分别记录。

## 图声书验收

另建图声书项目并重复导入/声音配置。只额外配置图像 Provider（例如已有 ComfyUI 工作流），不配置视频端点。至少安排两张关键帧，并保证每章开始有可显示的图片。可用密度控制创建锚定草稿，再修改场景提示词。

建议画面：雨夜室内门口、灯下纸箱与小猫。引用既有角色/场景参考图保持一致。导出 ZIP，解压后打开 index.html，或执行 `python -m http.server 8000` 再访问 localhost:8000。检查暂停、前后拖动、1.5 倍速与切章后的图片。

重做一句语音或改变其停顿，确认后续音效与切图时刻改变，旧导出不再显示为当前完成结果。暂时停掉模型服务，让某一段失败；重开项目、恢复服务后仅重试失败段，确认其他成功版本仍保留。

## 工程 QA 包

`uv run python scripts/book/make_fixture.py /tmp/new-book-fixture` 可生成无模型依赖的合成波形和色块图片播放包。它用于验证编码、混音、时间线和播放器，不是实际 TTS、图像模型或听感验收证据。
