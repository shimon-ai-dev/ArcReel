# 有声书与图声书 {#book-modes}

创建项目时选择输出模式：有声书（`audiobook`）、图声书（`illustrated_audiobook`）或原有视频（`video`）。输出模式与创作类型、视频生成方式是独立字段，创建后不支持切换。旧项目没有输出模式字段时按视频读取，不需要重写旧项目文件。

## 启动与升级 {#startup}

按[部署文档](../ops/deployment.md)备份数据并升级后端和前端。开发安装仍使用仓库根目录的 `uv sync`、`uv run alembic upgrade head`，以及 `frontend/` 下的 `pnpm install`。后端和前端必须来自同一功能分支。

书籍数据位于项目的 `book/` 下，保留原文、规范化文本、章节、稳定语音段、角色声音、表演指令与历史音频版本。重新打开项目后可以继续生成、重试失败段，成功产物不会因重试其他段而删除。

## 有声书制作 {#audiobook}

1. 创建有声书项目，导入小说全文。无需配置图像或视频模型。
2. 检查章节和语音分段。默认保留全部原文，包括章节标题、旁白和“他说”等叙述。自动划分不代表说话人识别已经正确，未确认的段落需由人或 Agent 校对。
3. 为旁白和各角色建立声音配置，逐段确认说话人。角色 ID 对应持久化声音配置，跨章节共用。
4. 设置情绪、表达描述和段后停顿。情绪与正文分开存储，不会直接拼进朗读文本。发音修正使用源文位置对应的独立替换映射，原文不变。
5. 生成语音并试听；失败段保留错误和重试入口。改变声音或表演参数只使相关段落的音频失效，停顿变化只重算时间线。
6. 导入音效、环境声或音乐，绑定语音段和偏移位置，设置音量、淡入淡出、循环与持续范围。环境声和音乐在人声区间降低音量。音效素材需自行确认使用权，素材来源保存在事件中。
7. 导出章节和整本 WAV 或 MP3。缺失、失败或过期的必需语音会阻止导出；正文覆盖检查与实际声音质量是不同检查，正文检查通过不等于发音、情绪或音色已验收。

时间线由实际音频采样长度与明确插入的静音计算，不依赖视频时长档位。图片和音效绑定语音段，重新生成语音后自动重算时刻。跨章音效保留循环相位与完整淡入淡出包络，不会在章边界重头播放；超出整本音频范围的音效须先修正，导出不会静默截断。

导出重新读取音频的实际长度，并校验已记录的语音摘要；完成收据保存源素材与导出文件的 SHA-256 摘要，文件被替换或损坏后不再显示为有效完成。图片必须能实际解码，仅有图片文件扩展名不足以通过导出。

## 本地情绪 TTS {#local-tts}

本地情绪适配器连接 ArcReel 提供的可选 IndexTTS2 桥接服务。它调用[官方 IndexTTS Python API](https://github.com/index-tts/index-tts)，不是官方发布的 HTTP API。桥接服务与 ArcReel 主程序分别运行，不会自动安装模型、下载权重或创建凭据。

先依照官方项目说明准备 IndexTTS2 的运行环境和模型权重，再在该环境中安装桥接运行所需的 FastAPI、Uvicorn、HTTPX。把 ArcReel 仓库路径加入 PYTHONPATH，然后执行：

```bash
PYTHONPATH=/path/to/ArcReel:$PYTHONPATH python /path/to/ArcReel/scripts/book/index_bridge.py \
  --model-dir /path/to/checkpoints_2 \
  --reference-root /path/to/voices \
  --port 7861
```

服务只监听 `127.0.0.1`。不要直接暴露到公网；跨机器部署所需的鉴权、反向代理与网络权限应由部署者单独配置。声音参考文件必须放在指定参考目录内；只接受相对文件名，不接受越界路径或符号链接。参考音频应由使用者拥有或获得使用授权。

角色声音选择 `indextts2`，服务地址填写 `http://127.0.0.1:7861`，参考音频填写如 `narrator.wav`。桥接固定使用官方 `indextts.infer_v2.IndexTTS2`，不是 `infer_v2_5`；不要将两代权重或接口混用。

该适配器明确支持：

- 中文与英文，单段最多 1000 字符；默认导入使用更短分段。
- 参考音频克隆声音。
- 八维情绪向量，顺序为快乐、愤怒、悲伤、恐惧、厌恶、低落、惊讶、平静。
- 自然语言情绪描述，通过模型的情绪分析功能转换，不加入正文。
- 情绪强度与程序插入的确定性停顿。

该适配器不声明语速控制或喘息、哭、笑等原生非语言标签能力。请求不支持的控制会明确报错，不会静默忽略。非语言发声可使用有来源记录的音效补充，但不能保证与克隆角色音色一致。通用 ArcReel TTS 供应商仍可复用，其能力保守声明；不能把普通 TTS 供应商当作天然支持情绪控制。

安装成功、接口可达和契约测试都不等于真实模型验证。只有实际调用模型生成并试听后，才可确认对应机器、权重与声音参考的可用性。

## 图声书制作与播放 {#illustrated}

图声书复用全部有声书能力，额外安排关键帧。每张图绑定一个语音段，可覆盖后续多段，直到下一张图开始；图片不必与 TTS 分段一一对应。每章开始需要有可显示的图片，可以沿用上一章末尾的图。

选择现有图像供应商，或按 [ComfyUI 接入说明](./comfyui.md)准备本地图像服务，再生成关键帧。图声书不查询必需视频能力，不生成 MP4，也不要求配置视频模型。

导出 ZIP 包包含章节音频、整本音频、图片、`manifest.json` 和 `index.html`。解压后可打开 `index.html`；播放器内嵌清单，不依赖读取本地 JSON 的 fetch 权限。若浏览器限制本地音频资源，在解压目录执行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。播放器以音频时钟同步图片和当前文本，支持暂停、拖动、倍速和章节切换，切换章节保留倍速。播放失败时页面显示本地服务启动提示。

## 验证与明确限制 {#verification}

当前交付尚未完成真实模型端到端生成与试听，也尚未完成浏览器实际播放验收；不能把下面的自动化测试结果视为这些验收已通过。需要部署可用模型服务与权重，并在可运行浏览器的环境中补齐验证。

单元测试验证情绪参数不混入正文、能力拒绝、桥接参数、覆盖完整性、停顿与混音；集成测试使用真实 ffmpeg 编解码 WAV/MP3，并验证导出包与完成收据。测试中的合成波形是工程测试数据，不是 TTS 产物。

生成可复现的播放器测试包：

```bash
uv run python scripts/book/make_fixture.py /tmp/new-book-fixture
node scripts/book/check_player.mjs /absolute/path/to/unzipped/index.html
```

浏览器检查使用前端 Playwright 依赖；系统 Chromium 可通过 `CHROMIUM_EXECUTABLE` 指定。脚本检查拖动切图、章节切换与倍速保持。没有实际运行浏览器或模型的环境不能据此宣称验收通过。

第一版不包含 M4B、自动生成音效、图声书转幻灯片视频，也不自动评估语音发音或角色音色质量。导出按章节混音，整本 WAV 逐章写入；超长单章应拆成较短章节，以控制内存占用。
