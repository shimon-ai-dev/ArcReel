# 有声书与图声书 {#book-modes}

目标是在原有小说/章节工作流上制作完整、自然的有声书，或配合原分镜图播放的图声书，不再建立另一套章节和关键帧工作区。

创建项目时选择 `audiobook`、`illustrated_audiobook` 或原有 `video`。输出模式创建后固定，缺失字段的旧项目仍按视频读取。按[部署文档](../ops/deployment.md)备份并更新同一分支的前后端，不自动改动 NAS 或模型服务。

## 使用原有工作台 {#audiobook}

1. 在原界面导入小说或章节，沿用章节导航、拆解审阅、角色/场景资产和右侧 Agent。原章节与正式剧本始终是内容真相源。
2. 内置拆解在原分镜内保留全部原文，标注说话人、表演意图、停顿及独立场景音意图。标注必须精确对应原文位置，不把情绪或音效说明混入朗读文字。未确认的说话人仍需校对。
3. 打开当前章节声音区域，同步已审阅章节，配置旁白和角色声音。原有角色声音参考可复用；修改原章节、参考声音或分镜后必须重新同步，旧导出不能代表新内容完成。
4. 生成缺失或失效语音，试听后再导出。重点核验克隆音色稳定、普通说话自然、情绪准确，以及停顿、拉长音、呼吸和哭笑等实际表现。不能因配置了表演意图就认定模型支持或效果合格。
5. 场景音、动作音和配乐是独立轨道。拆解得到的是意图，不是音效文件；需提供有使用权的素材并设置混音、范围和人声避让。

纯有声书跳过图像和视频步骤，不要求图像或视频模型。语音时间由实际音频长度和明确静音计算，不依赖视频时长档位。

## VOX 与能力边界 {#local-tts}

[VoxCPM2 接入说明](./voxcpm2.md)解释实际接口、参考音频和能力限制。VOX 与其他 TTS 的参数不能混用，不将 IndexTTS2 情绪向量或标签冒充 VOX 控制。普通 TTS、可选 IndexTTS2 桥接和 VOX 的能力分别核验；不支持的控制应明确报错，不静默忽略或切换声音。

模型安装、权重、服务地址和授权由部署者准备，不自动下载、登录或创建凭据。接口可达、契约测试通过不等于真实模型可用，更不等于试听验收通过。

## 图声书使用原分镜图 {#illustrated}

图声书的图片就是原有分镜图。沿用原图像 Provider、角色/场景/道具参考与分镜生成流程，再同步到音频播放锚点；不另建关键帧生成流程。可参考 [ComfyUI 接入](./comfyui.md)。隐藏并跳过视频生成、视频时间线与 MP4 阶段，原视频模式不受影响。

效果目标是自然真人剧质感、人物身份和场景连续性，而非默认动漫风。多角度头像、全身照及基础视图需要按实际模型参考图能力使用，不能把服务接受多张图片当作已实现一致性。

## 复用本地多视图资产 {#local-library}

原角色/场景资产面板支持导入预览与更新确认，不建立另一套资产工作区。先在能读取资产库的电脑上运行只读转换器，选择同时包含成品入口和归档内容的库根目录；转换器根据现有索引、确认记录和实际安全链接生成便携包，不要求手写新清单。再在原资产面板选择生成的目录，检查新增、更新、冲突和待定声音绑定后确认导入。转换命令与支持的目录规则见[现有资产库转换](./existing-library-bundles.md)。

归档版本、成品版本、人物基线、造型与场景状态分别保留。只读转换不会修改原库；导入不会因源文件缺失而删除已有项目引用。同一冻结版本不允许覆盖，明确选择不同版本须先预览，旧文件保留。声音技术检查通过不代表已试听、模型适配或克隆验收，声音与人物基线的适用关系未确认时不自动绑定。

原分镜生成只使用明确确认的视图，角色必须具备身份参考。优先给各角色和场景保留参考并兼顾前一分镜，再按镜头角度和景别分配额外头像/全身/造型视图；身份、服装与姿态的用途分开描述。数量以实际 Provider 的参考槽位为准，原提示词预览和生成回执列出采用及省略的视图，不保证所有七张图都会发送。

浏览器选择目录不是把任意电脑路径挂载到 NAS。成品目录中的链接可能指向归档外层，仅选择成品目录时转换会拒绝越界；需选择完整库根目录。此实现经过合成样例验证，实际库转换、NAS 挂载和真实画面一致性仍需在部署环境验收。

## 导出与验证 {#verification}

导出章节和全书 WAV/MP3；图声书另有含音频、原分镜图、manifest 与 HTML 播放器的 ZIP。解压打开 index.html；浏览器限制本地媒体时，可在解压目录运行本地静态服务。播放器支持暂停、跳转、章节选择及倍速，图像跟随实际音频时间。

缺失、失败、过期语音或不完整原文覆盖会阻止有效完成。导出检查实际媒体、摘要及导出收据，文件被替换或损坏后不能沿用完成状态。

已有合成素材播放器在 GitHub Actions 的 Chromium 中验证播放、暂停、前后跳转切图、切章及倍速保持，证据见仓库 `docs/verification/book-modes-2026-10-21.md`。单元与集成测试覆盖契约、原文范围、原工作流分支、混音与 ffmpeg 编解码。这些是工程测试，不是真实 TTS 或图像模型效果验收。

真实 VOX 试听、真实图像一致性及本地资产库适配仍需实际服务和素材验证。本阶段不包含 M4B、自动生成环境音、完整视频验收或自动音色质量评分。
